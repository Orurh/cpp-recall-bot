# Методика тренировки

Этот документ фиксирует правила, от которых зависят очередь вопросов, прогресс и
адаптивная сложность. Изменение этих правил должно сопровождаться тестами.

## Сессия

- Одна тренировка содержит до 10 уникальных вопросов.
- Вопросы добавляются партиями по три, чтобы сложность могла адаптироваться во время сессии.
- Приоритет: наступившие повторения, новые вопросы, затем ещё не наступившие повторения.
- Внутри одной группы выбирается вопрос, чья сложность ближе к текущему уровню темы.

## Навыки и зависимости

- Тема — широкая область для навигации, а `skill_id` — конкретное проверяемое умение.
- Каждый вопрос обязан ссылаться на известный навык из каталога.
- Каталог навыков задаёт ориентированный граф предварительных знаний и не допускает циклов.
- Банк можно фильтровать по `skill_id`; это основание для рекомендованного пути и экзаменов.
- Сложность вопроса, освоение навыка, прохождение программы и подтверждённый экзаменом уровень должны
  храниться независимо. Текущий адаптивный уровень пока управляет только подбором сложности.

## Готовность учебного модуля

- Первый модуль — `lifetime_raii`: storage duration → RAII → lifetime объектов → smart pointers.
- По каждому навыку модуль содержит минимум шесть независимых вопросов.
- Минимум три вопроса на навык должны требовать чтения, отладки или написания кода.
- `content-check` проверяет эти пороги и не позволяет случайно обеднить готовый модуль.
- Повторы одного вопроса учитываются как повторная практика, но не увеличивают охват уникальных вопросов.
- Прогресс навыка остаётся практическим свидетельством. Он не заменяет результат экзамена и не подтверждает уровень.

## Попытки

На каждый вопрос даётся до трёх попыток. Неверный ответ возвращает вопрос в конец очереди:
пользователь должен ещё раз извлечь ответ из памяти, а не тут же перебирать кнопки.

| Исход | Влияние на подтверждение уровня |
| --- | ---: |
| Верно с первой попытки | +2 |
| Верно со второй попытки | +1 |
| Верно с третьей попытки | 0 |
| Три неверных ответа | -2 |

Положительный балл не начисляется за вопрос ниже текущего уровня. Отрицательный балл не начисляется
за вопрос выше текущего уровня.

## Адаптивный уровень

Бот хранит общий уровень и отдельный уровень каждой темы. Каждый из них меняется только при накоплении:

- +4 баллов: уровень повышается, счётчик сбрасывается;
- -4 балла: уровень понижается, счётчик сбрасывается.

Так один случайный ответ не меняет сложность. Для повышения нужны как минимум два чистых ответа, для
понижения — два полных провала.

## Интервалы повторения

- Полный провал: 10 минут.
- Верно со второй или третьей попытки: 1 день без повышения стадии.
- Последовательные чистые ответы: 1, 3, 7, 14 и 30 дней.

## Метрики

- Точность сессии — доля верных ответов среди всех попыток.
- Освоено — число вопросов, закрытых верным ответом за три попытки.
- С первой попытки — отдельная метрика уверенного знания.
- Точность в общей статистике — доля успешно закрытых карточек.

## Будущие типы заданий

Открытый теоретический ответ и решение с кодом должны возвращать такой же структурированный результат,
как и текущие задания. Сама методика не должна зависеть от того, кто проверил ответ: локальная логика, ИИ или
изолированный runner.
