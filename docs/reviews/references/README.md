# Проверка привязок справки

`2026-10-26-bindings.json` фиксирует ожидаемые статьи для каждой редакции карточки,
включая отсутствие подходящей статьи. Это проверка релевантности справки, не
повторная техническая рецензия всех ответов и не независимый аудит.

Ошибка обнаружена владельцем в CR-000092: тег `vector` подбирал справку о ёмкости
и итераторах к вопросу о срезке объекта. Совпадение тега не доказывает релевантности.

Правила изменения:

1. Прочитать вопрос, код, варианты и разбор. Определить проверяемое правило.
2. Назначать только статьи, которые объясняют это правило или необходимую для
   решения предпосылку. Упоминания того же контейнера недостаточно.
3. При сомнении свериться с применимой редакцией стандарта или обсудить с владельцем.
   Если статьи пока нет, оставить пустой список, не подставлять общую по теме.
4. После содержательной проверки обновить конкретную связь в `reference_catalog.cc`
   и соответствующую запись матрицы. При изменении статьи проверить все её связи;
   хеш статьи охватывает весь текст, пример и источники. Не обновлять хеши всего
   реестра автоматически ради успешных тестов.
5. Выполнить `build/content_check`, `build/core_tests` и интеграционные проверки
   справки с отдельной тестовой БД. Матрица не заменяет чтение статьи человеком.

`CheckReferenceBindings` проверяет точные списки, отрицательные случаи, устаревшие
редакции, отсутствие строк и дубли. `CheckRealCardReferenceHelp` проверяет реальные
карточки и сохранение отметки помощи; CR-000092 отдельно проверяет отказ в чужой
статье без изменения снимка. Три новых примера ООП компилируются и исполняются в
`reviewed_examples_test.py`; C++-тест сверяет эти примеры с рабочим каталогом.

Технические основания новых статей и расширений — закреплённый C++23, N4950:
[копирование](https://timsong-cpp.github.io/cppwp/n4950/class.copy.ctor),
[виртуальные функции](https://timsong-cpp.github.io/cppwp/n4950/class.virtual),
[delete](https://timsong-cpp.github.io/cppwp/n4950/expr.delete),
[деструкторы](https://timsong-cpp.github.io/cppwp/n4950/class.dtor),
[временные объекты](https://timsong-cpp.github.io/cppwp/n4950/class.temporary),
[раскрутка стека](https://timsong-cpp.github.io/cppwp/n4950/except.ctor),
[vector](https://timsong-cpp.github.io/cppwp/n4950/vector.capacity),
[операции последовательностей](https://timsong-cpp.github.io/cppwp/n4950/sequence.reqmts).
Проверено 26 октября 2026 года. Исполнение примера не доказывает правило стандарта.

Дополнение RAII-ROUTE-01: матрица расширена до 185 карточек и 26 статей.
`unique_ptr_access`, `unique_ptr_move`, `unique_ptr_reset` объясняют разные операции;
из прежних связей дополнены только CR-000010 и CR-000146. Старые тексты статей и
редакции карточек не переписаны. Основания:
[создание](https://timsong-cpp.github.io/cppwp/n4950/unique.ptr.create),
[наблюдение](https://timsong-cpp.github.io/cppwp/n4950/unique.ptr.single.observers),
[перемещение](https://timsong-cpp.github.io/cppwp/n4950/unique.ptr.single.ctor#18),
[reset/release](https://timsong-cpp.github.io/cppwp/n4950/unique.ptr.single.modifiers),
[присваивание](https://timsong-cpp.github.io/cppwp/n4950/unique.ptr.single.asgn),
[std::move](https://timsong-cpp.github.io/cppwp/n4950/forward#10).
Пять новых карточек и примеры статей воспроизводятся автоматикой; гипотетическое
чтение удалённого объекта не исполняется. Результат — самопроверка EV-41.
